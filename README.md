# Orbital Structure Diagnostics via Canonical Summation and Entropy

This repository contains the scripts and figure sources used in the manuscript:

"Orbital Structure Analysis via Canonical Summation and Entropy Diagnostics: A Non-Spectral Framework for Classifying Quantum Probability Clouds"

## Contents

- `/scripts/`: Python and SageMath scripts to compute the canonical summation and entropy measures.
- `/figures/`: EPS versions of all plots used in the manuscript.
- `README.md`: This file.
- `LICENSE`: Open license (e.g., MIT or CC-BY).
